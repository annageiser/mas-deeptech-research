## How to use this document

When you cite a source in the thesis, update the **Status** column with `Cite · Bib`. When you read but don't yet cite, update to `Read`. The doc thus tracks both the reading queue and the citation coverage — useful for the supervisor meetings ("here are the sources I've engaged with so far").
