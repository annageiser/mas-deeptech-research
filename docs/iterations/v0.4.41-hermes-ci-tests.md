# v0.4.41 — hermes wrapper enters the CI pytest matrix

**Date:** 2026-06-29
**Closes:** Backlog item P2 #21 ("CI hermes matrix entry — either delete it or add `pyproject.toml` + real `tests/` directory") from [CLEAN_BACKLOG_NO_1.md](../../CLEAN_BACKLOG_NO_1.md).
**Scope:** new `systems/hermes/pyproject.toml`, new `systems/hermes/tests/test_reasoning_strip.py` (14 tests), addition of `hermes` to the `python-tests` matrix in `.github/workflows/ci.yml`.

## Problem

The `python-tests` job in CI ran five Python systems (masfactory, reports, api, dashboard, evaluation) but explicitly excluded `hermes` with the comment "hermes is a docker wrapper around upstream NousResearch hermes-agent, not a Python package." That was true at the container layer but not at the wrapper-script layer: `systems/hermes/scripts/persist_signals.py` is 621 lines of pure Python and carries the v0.4.38 reasoning-token strip (`_strip_reasoning_artefacts`) — the Layer 2 defence the thesis cites by name in §3.4 as the reason System B is robust against frontier-reasoning model outputs. A regex regression in that helper would silently break every System B cron tick the next morning, and CI had no way to catch it.

## Under the Hood

Three small additions, no functional code touched:

- [systems/hermes/pyproject.toml](../../systems/hermes/pyproject.toml) — minimal `setuptools` project declaration with `httpx>=0.27` as the only runtime dependency (the only thing the persister imports at module top level) plus a `[tool.pytest.ini_options]` block that puts `scripts/` on `sys.path` so tests can `import persist_signals` directly without making the script a proper package. `py-modules = []` keeps `pip install .` from trying to install the wrapper as a library — the install exists only to pull `httpx` and the test deps in CI.

- [systems/hermes/tests/test_reasoning_strip.py](../../systems/hermes/tests/test_reasoning_strip.py) — 14 tests covering: empty input no-op, no-reasoning-tag no-op, balanced `<think>...</think>` strip, multiple balanced blocks, all six tag families (`think`, `thinking`, `reasoning`, `thought`, `analysis`, `scratchpad`), case-insensitivity (`re.IGNORECASE`), multi-line blocks (`re.DOTALL`), dangling opener before `{`, `[`, and ` ``` `, mid-text opener preserved (`^`-anchor only), and a realistic Nemotron 3 Ultra fixture that round-trips a complete agent output. All 14 pass locally under both `pytest` and the simulated CI install path (`pip install .` → `pip install pytest` → `pytest -q`).

- [.github/workflows/ci.yml](../../.github/workflows/ci.yml) — `hermes` added to the `python-tests` matrix. Comment updated to point at the v0.4.38 reasoning strip and at thesis §3.4 so a future reader can see why the entry exists.

The alternative ("delete the matrix slot") was explicitly rejected: the persister grew during v0.4.36–v0.4.38 from a thin Supabase upsert into a load-bearing parser, and the thesis claims engineering-discipline coverage in §3.5.4. Shipping CI coverage that omits the v0.4.38 defence layer would have weakened that claim.
