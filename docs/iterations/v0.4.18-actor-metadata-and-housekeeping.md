# v0.4.18 — Actor metadata fix + log rotation + stale-container preflight + compare-page banner

**Date**: 2026-06-11
**Trigger**: Post-Phase-B audit ("what's left now that real Hermes is running daily?"). Five small issues bundled.

## What changed

### 1. Actor metadata bug

Symptom: the cron prompt going to the Hermes agent had the wrong values in the wrong slots:

```
Aliases: national_initiative
Website:
Category:
```

`Aliases` got the `Category` value; `Website` and `Category` were empty.

Two bugs combined:
- **Field-name mismatch**: the YAML uses `homepage`, Python read `a.get("website", "")`. Fields like website would always be empty.
- **dash `read` collapses consecutive empty TSV delimiters**: `#!/bin/sh` selects dash on Debian. When two adjacent TSV fields are empty (aliases + website), dash's `read` with `IFS=$'\t'` collapses them. Fields shift left and category lands in the aliases slot.

Fix: `#!/usr/bin/env bash` shebang + read `homepage` (with `website` fallback) from YAML.

### 2. Stale-container preflight

Symptom: when a prior hermes-run-* container got stuck (SSH disconnect mid-run, hard-fail mid-actor), the next cron tick hit `s6-log: fatal: unable to lock /opt/data/logs/gateways/default/lock: Resource busy` and aborted before any actor ran.

Fix: prepend a `docker rm -f` of all `mas-deeptech-research-hermes-run-*` containers to the cron entry (host side, before the docker compose run). `2>/dev/null || true` makes it a silent no-op when nothing stale exists.

### 3. Log rotation

Each cron run writes ~80 files into `state/runs/<UTC-iso>/` (40 actors × stdout+stderr). At daily cadence that's ~2400 files/30d. Cheap to prune; added a `find … -mtime +30 -delete` inside `collect_all_actors.sh` so the housekeeping runs every cron.

### 4. `/compare` page banner — System B identity transition

Before 2026-06-10 the `system='hermes'` rows came from the pattern impl. After 2026-06-10 they come from the real CLI. Same DB namespace, different software. The `/compare` page now shows a banner explaining the transition + one-click shortcuts:

- "Restrict to post-2026-06-10 (real Hermes CLI only)" — uses today − 2026-06-10 as the window
- 30d / 90d / 1y window switches
- Link to the methodology page for the full story

### 5. Threats-to-validity §§ 2.6 + 2.7

## Lessons (small but worth remembering)

1. **YAML field-name conventions matter.** If you rename a column once in actors.yaml, every reader in the repo needs to follow. We have no central schema for `actors.yaml`; a flat-list-of-dicts is the contract.
2. **`#!/bin/sh` is dash on Debian.** When you need POSIX-spec `read` behaviour with non-whitespace `IFS`, use bash explicitly.
3. **Container audit-folder accumulation is cheap to prevent but expensive to retrofit.** Prune at run-start; never at "we'll deal with it later".
