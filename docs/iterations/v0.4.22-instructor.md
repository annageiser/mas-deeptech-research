# v0.4.22 — `instructor` for structured-output discipline (System A)

**Date**: 2026-06-12
**Closes**: task #126

## What hurt before

Persistence parsed `classified_json` with `json.loads` and treated the
result as untyped:

```python
classified = _safe_json_load(attrs.get("classified_json", "")).get("classified", [])
# ... then later ...
for s in surviving:                                       # s is a raw dict
    rows.append(SignalRow(
        actor_slug=s["actor_slug"],                       # KeyError if missing
        is_technical=bool(s["is_technical"]),
        confidence=float(s.get("confidence", 0.0)),       # silent default
        dimension=normalise_dimension(s.get("dimension", "")),
        ...
    ))
```

Failure modes that already happened (or are one bad-model-run away):
- **Silent default**: `confidence` missing → `0.0` row written, signal
  gets buried at the bottom of every leaderboard.
- **Type drift**: `confidence: "high"` (model used the prompt vocabulary)
  → `float("high")` raises mid-loop, the whole batch crashes after
  partially writing rows.
- **Missing dimension**: persisted as empty string, which Supabase
  accepts but downstream scoring treats as `unknown`.

## What ships

### New module `masfactory_system/structured_output.py`

Two helpers, both pure functions:

```python
validate_classified_batch(raw: list) -> (valid: list[dict], invalid: list[dict])
```

Runs every entry through `ClassifiedSignal.model_validate()`. Returns a
`(valid, invalid)` split. `valid` entries are `model_dump(mode="json")`
outputs — same shape as before but with:

- Type coercion (`"0.7"` → `0.7`).
- Default values applied (`defense_engagement: False`, etc.).
- `signal_type` filled from `dimension` via the canonical map when
  absent.
- Legacy `dimension` keys normalised (v0.3.0 → v0.4.x).

```python
instructor_repair(raw_entry: dict) -> dict | None
```

The opt-in repair path. When `MASF_INSTRUCTOR_REPAIR=1`, uses
`instructor.from_openai(...)` to ask OpenRouter to re-emit `raw_entry`
as a `ClassifiedSignal`-shaped object. Costs one Chat Completions call
per invalid entry. Off by default to keep the daily token budget
predictable.

Reads `OPENROUTER_API_KEY`, `OPENROUTER_BASE_URL`, `MASF_MODEL_MAIN`
directly from `os.environ` so the persistence CustomNode doesn't have
to thread `Settings` through its `attrs` dict.

### Wired into `agents/persistence.py`

Right after the actor-attribution validation (line ~164) and before the
SignalRow construction loop:

```python
schema_valid, schema_invalid = validate_classified_batch(surviving)
if instructor_repair_available() and schema_invalid:
    for record in schema_invalid:
        repaired = instructor_repair(record["raw"])
        if repaired is not None:
            schema_valid.append(repaired)
            record["repaired"] = True
audit.write_json("dropped_validation.json", schema_invalid)
audit.write_json("validation_summary.json", {...})
surviving = schema_valid
```

Per-run audit folder now gains:
- `dropped_validation.json` — one entry per drop: `{"raw": <original>,
  "errors": [<pydantic errors>], "repaired": <bool>}`.
- `validation_summary.json` — `{validated_in, validated_out, invalid,
  repaired, instructor_repair_enabled}`. Cheap drop-rate metric for the
  thesis evaluation chapter.

### New tests

`tests/test_structured_output.py` covers:
- Valid-entry passthrough.
- Auto-fill of `signal_type` from `dimension`.
- Type coercion (`"0.7"` → `0.7`).
- Drop on bad type (`"high"` confidence).
- Drop on missing required field.
- Graceful handling of non-dict input.
- Repair gate respects `MASF_INSTRUCTOR_REPAIR`.

## Operator runbook

After `git pull` on the VPS:

```bash
docker compose build masfactory     # adds instructor to the venv
docker compose up -d
```

Nothing else needs to change. The validate-only path is on
unconditionally and has no token cost. To opt into repair:

```env
# in .env
MASF_INSTRUCTOR_REPAIR=1
```

then restart. Expect the cron run to log a non-zero
`validation_summary.invalid` count if the model occasionally drifts,
and a non-zero `repaired` count if repair is enabled.

## What this is NOT

- **Not** an instructor-everywhere rewrite. The masfactory framework's
  `Agent` nodes keep their string-output Chat-Completions plumbing.
  Instructor sits at the validation boundary, not as a replacement
  client.
- **Not** an extra LLM call in the default path. Validation is local
  (pydantic); only repair calls the LLM, and that's opt-in.
- **Not** wired into System B. Hermes persists via its own
  `persist_signals.py` which already does similar
  per-signal-type validation. A future `v0.4.2x` could mirror this
  structured-output module there if drift becomes an issue.

## Threat to validity touched

Closes one implicit row in `docs/threats-to-validity.md`: "Classifier
output schema not enforced at persistence — type drift could silently
corrupt rows." After v0.4.22 every persisted row passes
`ClassifiedSignal.model_validate()` exactly once before insertion, and
drops are auditable per run.
